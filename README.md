# Riftbreak Protocol

An original, low-poly top-down survival shooter built with Three.js, Vite, and TypeScript.

## Run

```bash
npm install
npm run dev
```

Production build: `npm run build`.

## Controls

- Move: WASD / arrow keys / virtual joystick
- Dash: Space / DASH control
- Active skill: E / SKILL control

Progress is stored locally in `localStorage` under `riftbreak-protocol-save-v1`.
